## গোলারং-এ স্লাইস (Slice) কী?

Go-তে Array নিয়ে কাজ করার একটা বড় সমস্যা হলো, এর সাইজ আগে থেকেই ফিক্সড করে দিতে হয়। ধরুন আপনি ৫ সাইজের একটা অ্যারে বানালেন, কিন্তু পরে আপনার ৬টা ডেটা রাখার দরকার হলো—তখন আর উপায় থাকে না।

এই ঝামেলা দূর করতেই এসেছে 'Slice'। স্লাইসকে আপনি একটা রাবার ব্যান্ডের মতো ভাবতে পারেন, যেটা আপনার দরকার অনুযায়ী বড় হতে পারে।

মজার ব্যাপার হলো, স্লাইস নিজে কিন্তু কোনো ডেটা সরাসরি ধরে রাখে না। সে আসলে পেছনের একটা আসল অ্যারের (underlying array) দিকে আঙুল দিয়ে দেখিয়ে দেয়। এর তিনটি অংশ থাকে:

1. **পয়েন্টার (Pointer):** এটি মূল অ্যারের প্রথম উপাদানটিকে নির্দেশ করে যেখান থেকে স্লাইসটি শুরু হয় এবং ডেটা অ্যাক্সেস করতে পারে।
2. **দৈর্ঘ্য বা লেন্থ (Length - `len`):** স্লাইসে বর্তমানে কতগুলো উপাদান আছে তার সংখ্যা।
3. **ধারণক্ষমতা বা ক্যাপাসিটি (Capacity - `cap`):** পয়েন্টার থেকে শুরু করে মূল অ্যারেটি সর্বোচ্চ কতগুলো উপাদান ধারণ করতে পারে তার সংখ্যা।

যদি আপনি `append` ব্যবহার করে স্লাইসে নতুন উপাদান যুক্ত করেন এবং তা ক্যাপাসিটি অতিক্রম করে, তবে Go স্বয়ংক্রিয়ভাবে একটি নতুন এবং বড় অ্যারে তৈরি করবে, আগের উপাদানগুলো সেখানে কপি করবে এবং স্লাইসটিকে নতুন অ্যারের সাথে যুক্ত করবে।

## গোলারং-এ স্লাইস তৈরি করার বিভিন্ন উপায়

Go-তে মূলত চারটি উপায়ে স্লাইস ডিফাইন বা তৈরি করা যায়:

### ১. স্লাইস লিটারেল (Slice Literal)

যখন আপনি আগে থেকেই ভ্যালুগুলো জানেন, তখন এটি সবচেয়ে বেশি ব্যবহৃত হয়। এটি অনেকটা অ্যারে তৈরি করার মতোই, শুধু থার্ড ব্র্যাকেট `[]` এর ভেতর কোনো সংখ্যা বা আকার দিতে হয় না।

```go
// এটি ৩ লেন্থ এবং ৩ ক্যাপাসিটির একটি স্লাইস তৈরি করে
mySlice := []int{10, 20, 30}

```

### ২. `make()` ফাংশন ব্যবহার করে

যখন আপনার একটি নির্দিষ্ট লেন্থ এবং/অথবা ক্যাপাসিটির স্লাইস ডায়নামিকভাবে তৈরি করার প্রয়োজন হয়, তখন `make` বিল্ট-ইন ফাংশনটি বেশ কার্যকরী। এর সবগুলো উপাদান তাদের জিরো ভ্যালু (zero value) দ্বারা পূর্ণ থাকে (যেমন- int এর জন্য `0`, string এর জন্য `""`)।

```go
// make(type, length, capacity)
slice1 := make([]int, 5)     // লেন্থ ৫, ক্যাপাসিটি ৫। উপাদানগুলো হলো: [0,0,0,0,0]
slice2 := make([]int, 3, 10) // লেন্থ ৩, ক্যাপাসিটি ১০।

```

### ৩. বিদ্যমান অ্যারে বা স্লাইস থেকে (Slicing)

`[low:high]` সিনট্যাক্স ব্যবহার করে আপনি একটি আগে থেকে থাকা অ্যারে বা অন্য একটি স্লাইসের নির্দিষ্ট অংশ কেটে নতুন স্লাইস তৈরি করতে পারেন। এটি `low` ইনডেক্স থেকে শুরু হয় কিন্তু `high` ইনডেক্স এর আগের উপাদান পর্যন্ত নেয় (অর্থাৎ high এক্সক্লুসিভ)।

```go
primes := [6]int{2, 3, 5, 7, 11, 13} // এটি একটি অ্যারে
var s []int = primes[1:4]            // ইনডেক্স ১ থেকে ৩ পর্যন্ত স্লাইস করে
// s এখন [3, 5, 7]

```

### ৪. `nil` স্লাইস ডিক্লেয়ার করা

আপনি কোনো ইনিশিয়ালাইজেশন ছাড়াই একটি স্লাইস ডিক্লেয়ার করতে পারেন। এর লেন্থ এবং ক্যাপাসিটি `0` থাকে এবং এর কোনো আন্ডারলায়িং অ্যারে থাকে না। খালি ফলাফল রিটার্ন করতে বা `append()` এর মাধ্যমে ডায়নামিকভাবে স্লাইস তৈরি করার ক্ষেত্রে এটি ব্যবহার করা হয়।

```go
var mySlice []int // mySlice হলো nil

```

## গোল্যাঙ-এ ভেরিয়াডিক ফাংশন (Variadic Function) কী?

ধরুন আপনি একটা যোগ করার ফাংশন বানালেন। কিন্তু আপনি জানেন না ইউজার কয়টা সংখ্যা যোগ করতে দেবে। সে চাইলে ২টা সংখ্যাও দিতে পারে, আবার ১০টাও দিতে পারে। এই ধরনের পরিস্থিতিতে আমরা ভেরিয়াডিক ফাংশন ব্যবহার করি। অর্থাৎ, যে ফাংশনে আপনি আপনার ইচ্ছামতো যত খুশি ডেটা পাঠাতে পারবেন।

### কীভাবে বানাবেন?

ফাংশন বানানোর সময় শেষ প্যারামিটারের নামের পর শুধু তিনটা ডট (...) বসিয়ে দিলেই হয়। আর মজার বিষয় হলো, ফাংশনের ভেতরে গেলে এই ডেটাগুলো আসলে একটা 'স্লাইস' হিসেবেই কাজ করে!

### উদাহরণ: ভেরিয়াডিক ফাংশন তৈরি এবং কল করা

```go
// ফাংশনের ভেতরে 'nums' প্যারামিটারটি ইন্টিজারের একটি স্লাইস হিসেবে কাজ করবে
func sum(nums ...int) int {
    total := 0
    for _, num := range nums {
        total += num
    }
    return total
}

func main() {
    // আপনি যেকোনো সংখ্যক আর্গুমেন্ট পাস করতে পারবেন
    fmt.Println(sum(1, 2))       // আউটপুট: 3
    fmt.Println(sum(1, 2, 3, 4)) // আউটপুট: 10
    fmt.Println(sum())           // আউটপুট: 0
}

```

> **নোট:** আপনার কাছে যদি আগে থেকেই একটি স্লাইস থাকে এবং আপনি সেটি একটি ভেরিয়াডিক ফাংশনে পাস করতে চান, তবে আপনি স্লাইস ভেরিয়েবলের ঠিক পরেই `...` যোগ করে সেটিকে "আনপ্যাক" (unpack) বা আলাদা করতে পারেন:
>
> ```go
> myNumbers := []int{10, 20, 30}
> result := sum(myNumbers...) // স্লাইসটিকে আলাদা আলাদা আর্গুমেন্ট হিসেবে আনপ্যাক করে
>
> ```
