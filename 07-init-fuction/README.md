Go ল্যাঙ্গুয়েজে `init` ফাংশন একটি অত্যন্ত গুরুত্বপূর্ণ এবং বিশেষ ফাংশন। এটি মূলত প্রোগ্রামের মূল কাজ শুরু হওয়ার আগে কিছু **প্রস্তুতিমূলক কাজ** (Initialization) করার জন্য ব্যবহৃত হয়।

নিচে সহজভাবে এর ব্যাখ্যা দেওয়া হলো:

## ১. `init` ফাংশন কী?

Go-তে `init` হলো এমন একটি ফাংশন যা আপনি নিজে কল করেন না; এটি রানটাইমে **অটোমেটিক** বা স্বয়ংক্রিয়ভাবে কল হয়। একটি প্যাকেজের ভেতরে যতগুলো গ্লোবাল ভ্যারিয়েবল আছে, সেগুলো সেট হওয়ার ঠিক পরেই এবং `main` ফাংশন শুরু হওয়ার ঠিক আগে `init` কাজ করে।

### এক্সিকিউশন অর্ডার (কখন কাজ করে):

১. প্যাকেজ লেভেলের ভ্যারিয়েবলগুলো ডিক্লেয়ার হয়।  
২. `init` ফাংশন রান করে।  
৩. সবশেষে `main` ফাংশন রান করে।

## ২. প্রধান বৈশিষ্ট্যসমূহ

- **প্যারামিটারহীন:** এই ফাংশনে কোনো আর্গুমেন্ট পাঠানো যায় না এবং এটি কিছু রিটার্নও করে না।
- **একাধিক `init`:** একটি প্যাকেজে বা একটি ফাইলে একাধিক `init` ফাংশন থাকতে পারে। সেগুলো কোডে যেভাবে লেখা হয়েছে, সেই সিরিয়াল অনুযায়ী কাজ করবে।
- **একবারই রান করে:** একটি প্যাকেজ যদি অনেক জায়গায় ইমপোর্ট করা হয়, তবুও `init` ফাংশনটি পুরো প্রোগ্রামে মাত্র একবারই রান করবে।
- **অদৃশ্য ব্যবহার:** আপনি কোডের অন্য কোথাও থেকে `init()` লিখে একে কল করতে পারবেন না।

## ৩. কেন ব্যবহার করবেন?

সাধারণত নিচের কাজগুলোর জন্য এটি ব্যবহার করা হয়:

- **এনভায়রনমেন্ট চেক:** প্রোগ্রাম চলার জন্য প্রয়োজনীয় ফাইল বা এনভায়রনমেন্ট ভ্যারিয়েবল আছে কি না তা পরীক্ষা করা।
- **ডাটাবেস কানেকশন:** মেইন প্রোগ্রাম শুরু হওয়ার আগে ডাটাবেস বা এক্সটার্নাল সার্ভিসের সাথে সংযোগ নিশ্চিত করা।
- **রেজিস্ট্রেশন:** কোনো ড্রাইভার (যেমন SQL ড্রাইভার) রেজিস্টার করা।

## ৪. একটি সহজ উদাহরণ

নিচের কোডটি দেখলে আপনি বুঝতে পারবেন কোনটি আগে প্রিন্ট হচ্ছে:

```go
package main

import "fmt"

// গ্লোবাল ভ্যারিয়েবল
var name string


func main() {
    fmt.Printf("২. হ্যালো %s, এটি main ফাংশন।\n", name)
}

// init ফাংশন
func init() {
    name = "Binance User"
    fmt.Println("১. এটি init ফাংশন, যা সবার আগে রান করছে!")
}

```

**আউটপুট:**

```text
১. এটি init ফাংশন, যা সবার আগে রান করছে!
২. হ্যালো Binance User, এটি main ফাংশন।

```

## ৫. বিশেষ সতর্কতা

`init` ফাংশন খুব সাবধানে ব্যবহার করা উচিত। যেহেতু এটি প্রোগ্রামের শুরুতে নিজে নিজেই রান করে, তাই এখানে যদি কোনো বড় ভুল থাকে (যেমন `panic` কল করা হয়), তবে আপনার পুরো প্রোগ্রামটি `main` পর্যন্ত পৌঁছানোর আগেই ক্র্যাশ করবে। একে ইউনিট টেস্ট (Unit Test) করাও কিছুটা কঠিন।

---

## ১. প্যাকেজ ইমপোর্ট অর্ডারের চিত্র

একাধিক প্যাকেজ যখন একে অপরের ওপর নির্ভরশীল হয়, তখন Go একটি নির্দিষ্ট চেইন বা ক্রম অনুসরণ করে `init` ফাংশনগুলো রান করায়। এটি মূলত **"Bottom-up"** পদ্ধতিতে কাজ করে।

সহজ কথায়, আপনার `main` প্যাকেজ যদি অন্য কোনো প্যাকেজ (যেমন `Pkg A`) ইমপোর্ট করে, তবে আগে `Pkg A`-এর `init` রান হবে, তারপর `main`-এর `init` রান হবে।

ধরুন `Main` প্যাকেজটি `A` এবং `B` কে ইমপোর্ট করছে, আবার `A` ইমপোর্ট করছে `C` কে।

### এক্সিকিউশন সিরিয়াল:

১. **Package C:** যেহেতু এটি সবার নিচে (কারো ওপর নির্ভরশীল নয়), এর `init` সবার আগে রান করবে।  
২. **Package A:** `C` তৈরি হয়ে যাওয়ার পর `A`-এর `init` রান করবে।  
৩. **Package B:** এরপর `B`-এর `init` রান করবে।  
৪. **Package Main:** সবশেষে মেইন প্যাকেজের `init` এবং তারপর `main()` ফাংশন রান করবে।

## ২. প্র্যাকটিক্যাল কোড উদাহরণ

ধরা যাক আমাদের দুটি ফাইল আছে: `auth` প্যাকেজ এবং `main` প্যাকেজ।

### `auth/auth.go` ফাইল:

```go
package auth

import "fmt"

func init() {
    fmt.Println("১. Auth প্যাকেজ ইনভ্যালিড সেশন চেক করছে...")
}

```

### `main.go` ফাইল:

```go
package main

import (
    "fmt"
    _ "example/auth" // শুধু init রান করার জন্য ব্ল্যাঙ্ক ইমপোর্ট
)

func init() {
    fmt.Println("২. Main প্যাকেজ কনফিগারেশন লোড করছে...")
}

func main() {
    fmt.Println("৩. এখন মেইন ফাংশন রান করছে।")
}

```

### আউটপুট:

```text
১. Auth প্যাকেজ ইনভ্যালিড সেশন চেক করছে...
২. Main প্যাকেজ কনফিগারেশন লোড করছে...
৩. এখন মেইন ফাংশন রান করছে।

```

## ৩. গুরুত্বপূর্ণ কিছু পয়েন্ট

- **সাইক্লিক ডিপেন্ডেন্সি (Cyclic Dependency):** Go-তে আপনি এমনভাবে ইমপোর্ট করতে পারবেন না যেখানে `A` ইমপোর্ট করে `B`-কে আর `B` ইমপোর্ট করে `A`-কে। এটি করলে কম্পাইল টাইম এরর দেবে।
- **ব্ল্যাঙ্ক ইমপোর্ট (`_`):** অনেক সময় আমরা কোনো প্যাকেজের ফাংশন সরাসরি ব্যবহার করি না, কিন্তু চাই সেটির `init` ফাংশনটি রান করুক (যেমন: ডাটাবেস ড্রাইভার সেটআপ)। তখন `import _ "package_name"` ব্যবহার করা হয়।
- **একই ফাইলে একাধিক `init`:** যদি একই ফাইলে ৩টি `init` ফাংশন থাকে, তবে সেগুলো টপ-টু-বটম (উপর থেকে নিচে) সিরিয়ালে রান করবে।

---

> **একটি মজার তথ্য:** `init` ফাংশন কিন্তু প্রোগ্রামের পারফরম্যান্সে প্রভাব ফেলতে পারে। যদি অনেক বেশি প্যাকেজে ভারী কাজ `init`-এ রাখা হয়, তবে আপনার অ্যাপ্লিকেশনটি চালু হতে (Startup time) অনেক সময় নেবে।
