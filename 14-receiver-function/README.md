Go-তে **receiver function** (যাকে সাধারণত **method** বা মেথড বলা হয়) হলো এমন একটি ফাংশন যা কোনো নির্দিষ্ট টাইপের (type) সাথে যুক্ত থাকে। অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং ভাষায় (যেমন Java বা C++) ক্লাসের ভেতর যেমন মেথড থাকে, এটি ঠিক তেমনই কাজ করে। এর মাধ্যমে আপনি আপনার কাস্টম টাইপ বা স্ট্রাকটকে (struct) নিজস্ব কিছু কাজ করার ক্ষমতা বা "behavior" দিতে পারেন।

আলাদা কোনো ফাংশন তৈরি করে সেখানে আর্গুমেন্ট হিসেবে ভেরিয়েবল পাস করার বদলে, আপনি ফাংশনটিকে সরাসরি সেই টাইপের সাথেই যুক্ত করে দেন।

## সিনট্যাক্স (The Syntax)

একটি মেথড দেখতে সাধারণ ফাংশনের মতোই, পার্থক্য হলো মেথডের নামের আগে একটি অতিরিক্ত প্যারামিটার থাকে। এই অতিরিক্ত প্যারামিটারটিকেই **receiver** বলা হয়।

```go
func (receiverName ReceiverType) MethodName(args...) ReturnType {
    // মেথডের ভেতরের কাজ
}

```

### একটি বাস্তব উদাহরণ

নিচে একটি `Rectangle` (আয়তক্ষেত্র) স্ট্রাকটের সাথে কীভাবে `Area` (ক্ষেত্রফল) মেথড যুক্ত করতে হয় তা দেখানো হলো:

```go
package main

import "fmt"

type Rectangle struct {
    width, height float64
}

// "Area" হলো একটি মেথড যার রিসিভার টাইপ হলো "Rectangle"
func (r Rectangle) Area() float64 {
    return r.width * r.height
}

func main() {
    rect := Rectangle{width: 10, height: 5}

    // ডট (dot) নোটেশন ব্যবহার করে মেথড কল করা
    fmt.Println("Area:", rect.Area())
}

```

> **নোট:** রিসিভারগুলো সাধারণত `struct` এর সাথেই বেশি ব্যবহার করা হয়, তবে আপনি আপনার প্যাকেজে তৈরি করা যেকোনো কাস্টম টাইপের সাথেই রিসিভার যুক্ত করতে পারেন (যেমন: `type MyFloat float64`)।

## Value Receivers বনাম Pointer Receivers

Go মেথড বোঝার ক্ষেত্রে এটি সবচেয়ে গুরুত্বপূর্ণ বিষয়। আপনি রিসিভারকে **value** হিসেবে অথবা **pointer** হিসেবে পাস করতে পারেন।

### ১. Value Receiver `(r Type)`

যখন আপনি value receiver ব্যবহার করেন, তখন Go মেথডের ভেতর সেই টাইপের একটি **হুবহু কপি** তৈরি করে পাঠায়।

- **কী ঘটে:** মেথডের ভেতর রিসিভারের কোনো পরিবর্তন করলে তা আসল ভেরিয়েবলে কোনো প্রভাব ফেলে না। শুধুমাত্র কপিটি পরিবর্তন হয়।
- **কখন ব্যবহার করবেন:** যখন আপনার ডাটা পরিবর্তন করার দরকার নেই, অথবা স্ট্রাকটটি আকারে অনেক ছোট (তাই কপি করলে খুব একটা মেমরি খরচ হয় না)।

### ২. Pointer Receiver `(r *Type)`

যখন আপনি pointer receiver ব্যবহার করেন, তখন আপনি মেমরি অ্যাড্রেস বা রেফারেন্স পাস করেন।

- **কী ঘটে:** মেথডের ভেতর কোনো পরিবর্তন করলে তা **সরাসরি আসল ভেরিয়েবলকে পরিবর্তন করে**।
- **কখন ব্যবহার করবেন:** যখন মেথডের মাধ্যমে আপনার স্ট্রাকটের ভেতরের ডাটা পরিবর্তন (mutate) করার প্রয়োজন হয়, অথবা স্ট্রাকটটি অনেক বড় হয় (যাতে বারবার কপি করলে মেমরি নষ্ট না হয়)।

### কোডের মাধ্যমে পার্থক্য

```go
package main

import "fmt"

type Counter struct {
    count int
}

// Value receiver: এটি শুধু একটি কপির উপর কাজ করে
func (c Counter) IncrementValue() {
    c.count++
}

// Pointer receiver: এটি আসল ডাটা পরিবর্তন করে
func (c *Counter) IncrementPointer() {
    c.count++
}

func main() {
    counter := Counter{count: 0}

    counter.IncrementValue()
    fmt.Println("After Value Receiver:", counter.count) // আউটপুট: 0 (আসল ডাটা বদলায়নি)

    counter.IncrementPointer()
    fmt.Println("After Pointer Receiver:", counter.count) // আউটপুট: 1 (আসল ডাটা বদলেছে)
}

```

## কখন কোনটি ব্যবহার করবেন? (Quick Decision Guide)

| Pointer Receiver (`*T`) ব্যবহার করবেন যদি...                                          | Value Receiver (`T`) ব্যবহার করবেন যদি...                                                          |
| ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| রিসিভারের ভেতরের ডাটা পরিবর্তন (modify) করতে হয়।                                     | শুধু রিসিভারের ডাটা পড়তে (read) হয়, পরিবর্তন করার প্রয়োজন না থাকে।                              |
| স্ট্রাকটটি অনেক বড় হয় (যাতে কপি করার সময় বাঁচে)।                                   | টাইপটি ছোট স্ট্রাকট, `int`, `string` বা `bool` হয়।                                                |
| ঐ টাইপের অন্য কোনো মেথড পয়েন্টার রিসিভার ব্যবহার করে (সব মেথডে একই নিয়ম রাখা ভালো)। | টাইপটি ম্যাপ (map), স্লাইস (slice) বা চ্যানেল (channel) হয় (কারণ এগুলো আগে থেকেই রেফারেন্স টাইপ)। |
