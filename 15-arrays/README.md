## অ্যারে (Array) কী?

কম্পিউটার সায়েন্সে, অ্যারে হলো এমন একটি ডেটা স্ট্রাকচার যেখানে একই ডেটা টাইপের একাধিক উপাদান মেমোরির পাশাপাশি (contiguous) লোকেশনে সংরক্ষিত থাকে।

**Go (Golang)**-এ অ্যারের দুটি নির্দিষ্ট এবং কঠোর বৈশিষ্ট্য রয়েছে:

১. **নির্দিষ্ট দৈর্ঘ্য (Fixed Length):** অ্যারে তৈরির সময় এর সাইজ বা আকার নির্ধারণ করে দিতে হয় এবং পরবর্তীতে তা পরিবর্তন (কমানো বা বাড়ানো) করা যায় না।

২. **ভ্যালু টাইপ (Value Type):** সি (C) বা জাভার (Java) মতো প্রোগ্রামিং ল্যাঙ্গুয়েজে অ্যারে পয়েন্টার হিসেবে কাজ করলেও, Go-তে অ্যারে হলো **ভ্যালু**। আপনি যদি একটি অ্যারেকে অন্য একটি অ্যারের সমান করেন বা কোনো ফাংশনে পাস করেন, তবে Go সম্পূর্ণ অ্যারের ডেটা কপি করে নেয়।

## Golang-এ অ্যারের ব্যবহার

Go-তে কীভাবে অ্যারে ডিক্লেয়ার, ইনিশিয়ালাইজ এবং পরিচালনা করতে হয়, তার একটি বিস্তারিত বিবরণ নিচে দেওয়া হলো:

### ১. অ্যারে ডিক্লেয়ার (Declare) করা

অ্যারে ডিক্লেয়ার করার জন্য আপনাকে এর দৈর্ঘ্য (length) এবং এটি কী ধরনের উপাদান ধারণ করবে তার টাইপ নির্দিষ্ট করতে হবে। আপনি যদি কোনো ভ্যালু অ্যাসাইন না করেন, তবে Go স্বয়ংক্রিয়ভাবে সেই টাইপের "জিরো ভ্যালু" (zero value) দিয়ে অ্যারেকে পূর্ণ করে দেয় (যেমন- ইন্টিজারের জন্য `0`, স্ট্রিংয়ের জন্য `""`)।

```go
package main

import "fmt"

func main() {
    // ৫টি ইন্টিজার ধারণ করার জন্য একটি অ্যারে ডিক্লেয়ার করা
    var numbers [5]int
    fmt.Println(numbers) // আউটপুট: [0 0 0 0 0]
}

```

### ২. অ্যারে ইনিশিয়ালাইজ (Initialize) করা

অ্যারে লিটারেল (array literal) ব্যবহার করে আপনি অ্যারে তৈরির ঠিক একই মুহূর্তে এতে ভ্যালু অ্যাসাইন করতে পারেন।

```go
// নির্দিষ্ট দৈর্ঘ্য উল্লেখ করে
colors := [3]string{"red", "green", "blue"}

// "..." ব্যবহার করে কম্পাইলারকে উপাদান সংখ্যা গণনা করতে দিয়ে
fruits := [...]string{"apple", "banana", "cherry", "date"}

```

### ৩. উপাদান অ্যাক্সেস এবং পরিবর্তন (Accessing and Modifying Elements)

অ্যারে হলো জিরো-ইনডেক্সড, অর্থাৎ এর প্রথম উপাদানটির ইনডেক্স হলো `0`। কোনো ভ্যালু পড়তে বা পরিবর্তন করতে স্কোয়ার ব্র্যাকেট `[]` ব্যবহার করা হয়।

```go
scores := [3]int{90, 85, 88}

// কোনো উপাদান অ্যাক্সেস বা পড়া
fmt.Println("প্রথম স্কোর:", scores[0]) // আউটপুট: 90

// কোনো উপাদান পরিবর্তন করা
scores[1] = 95
fmt.Println("আপডেট করা স্কোর:", scores) // আউটপুট: [90 95 88]

```

### ৪. অ্যারে ইটারেট (Iterate) করা বা লুপ চালানো

অ্যারেতে লুপ চালানোর সবচেয়ে ভালো বা "Go-idiomatic" উপায় হলো `range` কীওয়ার্ড ব্যবহার করা, যা প্রতিটি উপাদানের ইনডেক্স এবং ভ্যালু উভয়ই প্রদান করে।

```go
animals := [...]string{"dog", "cat", "bird"}

// range ব্যবহার করে
for index, animal := range animals {
    fmt.Printf("ইনডেক্স: %d, প্রাণী: %s\n", index, animal)
}

// ইনডেক্স প্রয়োজন না হলে ব্ল্যাঙ্ক আইডেন্টিফায়ার (_) ব্যবহার করা যায়
for _, animal := range animals {
    fmt.Println("প্রাণী:", animal)
}

```

## Go অ্যারে সম্পর্কে একটি গুরুত্বপূর্ণ তথ্য

যেহেতু Go তে অ্যারের দৈর্ঘ্য কঠোরভাবে নির্দিষ্ট থাকে এবং এগুলো ভ্যালু হিসেবে কপি হয়, তাই দৈনন্দিন Go প্রোগ্রামিংয়ে সরাসরি অ্যারের ব্যবহার আসলে খুব কম হয়।

এর বদলে, Go ডেভেলপাররা প্রায় সবসময় **স্লাইস (Slices)** ব্যবহার করেন। স্লাইস হলো একটি আন্ডারলাইং অ্যারের উপাদানগুলোর একটি নমনীয় এবং পরিবর্তনযোগ্য-সাইজের (dynamically-sized) ভিউ। যখন আপনি `myList := []int{1, 2, 3}` এর মতো কোনো কোড দেখেন (লক্ষ্য করুন ব্র্যাকেটের ভেতরে কোনো সংখ্যা নেই), তখন সেটি আসলে একটি স্লাইস, অ্যারে নয়।
