Go (Golang)-এ **struct** (structure-এর সংক্ষিপ্ত রূপ) হলো একটি user-defined type (ব্যবহারকারীর তৈরি ডাটা টাইপ), যা আপনাকে বিভিন্ন ডাটা টাইপের (data types) ফিল্ডগুলোকে একসাথে একটি সিঙ্গেল ইউনিটে বা প্যাকেজে যুক্ত করার সুবিধা দেয়।

আপনি যদি অবজেক্ট-অরিয়েন্টেড প্রোগ্রামিং (যেমন: Python, Java, বা C++) ব্যাকগ্রাউন্ড থেকে এসে থাকেন, তবে আপনি struct-কে একটি 'class'-এর মতো ভাবতে পারেন। Go-তে কোনো class বা inheritance নেই, তাই কোনো অবজেক্টের অবস্থা (state) বা ডাটা সংরক্ষণ করার প্রধান উপায় হলো এই struct।

## ১. Struct ডিক্লেয়ার বা তৈরি করা

একটি struct তৈরি করতে `type` এবং `struct` কিওয়ার্ড ব্যবহার করা হয়। এর ভেতরে আপনি বিভিন্ন ফিল্ড এবং তাদের ডাটা টাইপগুলো লিস্ট করে দিতে পারবেন।

```go
type Employee struct {
    FirstName string
    LastName  string
    Age       int
    Salary    float64
}

```

## ২. Struct ইনিশিয়ালাইজ করা (ভ্যালু দেওয়া)

Go-তে একটি struct-এর ইন্সট্যান্স (instance) তৈরি করার কয়েকটি উপায় রয়েছে:

### উপায় ক: Zero Value (ডিফল্ট বা শূন্য মান)

আপনি যদি কোনো ভ্যালু না দিয়েই একটি struct ডিক্লেয়ার করেন, তবে Go স্বয়ংক্রিয়ভাবে সব ফিল্ডে "zero value" বা ডিফল্ট মান বসিয়ে দেয় (যেমন: স্ট্রিংয়ের জন্য `""`, int-এর জন্য `0`, বুলিয়ানের জন্য `false`)।

```go
var emp1 Employee
// emp1 এখন এমন হবে: {FirstName:"", LastName:"", Age:0, Salary:0.0}

```

### উপায় খ: Struct Literals (সবচেয়ে বেশি ব্যবহৃত)

আপনি চাইলে সরাসরি ভ্যালু অ্যাসাইন করে struct তৈরি করতে পারেন। ফিল্ডের নাম উল্লেখ করে ভ্যালু দেওয়াটা সবচেয়ে নিরাপদ ও ভালো উপায়।

```go
emp2 := Employee{
    FirstName: "Jane",
    LastName:  "Doe",
    Age:       28,
    Salary:    85000.50,
}

```

### উপায় গ: `new` কিওয়ার্ড ব্যবহার করে

`new` কিওয়ার্ডটি struct-এর জন্য মেমরিতে জায়গা বরাদ্দ (allocate) করে, সব ফিল্ডে zero value বসায় এবং এটি ওই struct-এর একটি **পয়েন্টার (pointer)** (`*Employee`) রিটার্ন করে।

```go
emp3 := new(Employee)
emp3.FirstName = "John"

```

## ৩. ফিল্ড এক্সেস এবং পরিবর্তন করা

Struct-এর ভেতরের কোনো ডাটা পড়তে বা পরিবর্তন করতে ডট (`.`) নোটেশন ব্যবহার করা হয়।

```go
// ফিল্ডের ভ্যালু পরিবর্তন করা
emp2.Salary = 90000.00

// ফিল্ডের ভ্যালু প্রিন্ট করা বা এক্সেস করা
fmt.Println(emp2.FirstName, "makes", emp2.Salary)

```

## ৪. Struct-এর সাথে মেথড (Methods) যুক্ত করা

Struct মূলত _ডাটা_ ধরে রাখে, কিন্তু আপনি চাইলে এর সাথে _কাজ বা behavior_ যুক্ত করতে পারেন মেথডের মাধ্যমে। Go-তে মেথড হলো সাধারণ ফাংশনের মতোই, তবে এতে ফাংশনের নামের আগে একটি স্পেশাল "receiver" আর্গুমেন্ট থাকে।

```go
// (e Employee) অংশটি হলো receiver
func (e Employee) FullName() string {
    return e.FirstName + " " + e.LastName
}

// ব্যবহার:
// name := emp2.FullName()

```

## ৫. Struct Tags (মেটাডাটা)

Go-এর struct-এর একটি খুব শক্তিশালী ফিচার হলো "tags"। এগুলো হলো ফিল্ডের টাইপের শেষে দেওয়া ছোট টেক্সট, যা অন্যান্য প্যাকেজকে (যেমন: JSON এনকোডার বা ডাটাবেস ORM) নির্দেশ দেয় যে এই ফিল্ডটির সাথে কীভাবে কাজ করতে হবে।

```go
type User struct {
    Username string `json:"username"`
    Password string `json:"-"` // "-" দেওয়ার মানে হলো JSON এনকোডার এই ফিল্ডটি বাদ দিয়ে দেবে
}

```
