Go-তে **Anonymous Function** এবং **IIFE** প্রোগ্রামিংকে আরও ফ্লেক্সিবল করে তোলে। নিচে এগুলোর ব্যাখ্যা দেওয়া হলো:

## ১. Anonymous Function (অজ্ঞাতনামা ফাংশন)

সাধারণত আমরা যখন কোনো ফাংশন লিখি, তখন তার একটি নাম দেই (যেমন: `func sayHello()`). কিন্তু **Anonymous Function** হলো এমন একটি ফাংশন যার কোনো **নাম থাকে না**।

### কেন ব্যবহার করবেন?

- যদি কোনো ফাংশন শুধুমাত্র একবার বা নির্দিষ্ট ছোট কোনো কাজের জন্য লাগে।
- অন্য কোনো ফাংশনের ভেতরে লজিক ডিফাইন করতে।
- ভেরিয়েবলের মধ্যে ফাংশন স্টোর করে রাখতে।

### উদাহরণ:

```go
package main
import "fmt"

func main() {
    // এখানে ফাংশনটির কোনো নাম নেই, এটি 'message' ভেরিয়েবলে সেভ করা হয়েছে
    message := func() {
        fmt.Println("হ্যালো, আমি একটি Anonymous Function!")
    }

    message() // ভেরিয়েবল ধরে কল করা হলো
}

```

## ২. IIFE (Immediately Invoked Function Expression)

IIFE হলো এমন একটি Anonymous Function যা ডিফাইন করার **সাথে সাথেই রান বা এক্সিকিউট হয়ে যায়**। এটি আলাদাভাবে কল করার প্রয়োজন পড়ে না।

Go-তে এটি করার নিয়ম হলো ফাংশনের শেষ ব্রাকেটের `}` পরেই এক জোড়া ফার্স্ট ব্রাকেট `()` বসিয়ে দেওয়া।

### উদাহরণ:

```go
package main
import "fmt"

func main() {
    // ফাংশনটি ডিফাইন করার সাথে সাথেই () দিয়ে কল করা হয়েছে
    func(name string) {
        fmt.Println("স্বাগতম,", name)
    }("বাংলাদেশ") // এখানে "বাংলাদেশ" আর্গুমেন্ট হিসেবে পাস করা হয়েছে
}

```

## ৩. কেন এবং কোথায় এগুলো ব্যবহার করবেন?

১. **Goroutines (কনকারেন্সি):** Go-তে যখন আমরা লুপের ভেতর থ্রেড বা Goroutine চালাই, তখন ডেটা সেফ রাখার জন্য IIFE ব্যবহার করা হয়।

```go
go func(x int) {
    fmt.Println(x)
}(10) // সাথে সাথে কল হয়ে ১০ প্রিন্ট করবে

```

২. **Defer Cleanup:** কোনো ফাইল ক্লোজ করা বা ডাটাবেস কানেকশন বন্ধ করার সময় `defer` এর সাথে এগুলো খুব কার্যকর।

```go
defer func() {
    fmt.Println("কাজ শেষ, এবার ক্লিনআপ করছি...")
}()

```

৩. **Variable Isolation:** যদি আপনি চান আপনার কোনো নির্দিষ্ট ভেরিয়েবল শুধুমাত্র ওই ফাংশনের ভেতরেই থাকুক (Global scope দূষিত না করে), তবে IIFE ব্যবহার করা বুদ্ধিমানের কাজ।

---

| বৈশিষ্ট্য       | Anonymous Function                       | IIFE                   |
| --------------- | ---------------------------------------- | ---------------------- |
| **নাম**         | থাকে না                                  | থাকে না                |
| **কখন রান হয়?** | যখন ভেরিয়েবল বা রেফারেন্স দিয়ে কল করা হয় | ডিফাইন করার সাথে সাথেই |
| **সিনট্যাক্স**  | `func() { ... }`                         | `func() { ... }()`     |
